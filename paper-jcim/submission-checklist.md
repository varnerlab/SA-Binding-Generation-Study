# JCIM submission checklist

## Manuscript package

- [x] Article type and `jcisd8` journal configuration selected in `Paper_JCIM.tex`.
- [x] Eight-word title (within the journal’s preferred concise-title range).
- [x] Abstract remains within the 250-word limit after synchronization with the arXiv version.
- [x] Eight keywords supplied.
- [x] 3.25 by 1.75 inch, 300 dpi TOC graphic supplied.
- [x] Data and Software Availability section supplied.
- [x] Author Contributions section supplied.
- [x] Notes/competing financial interest statement supplied.
- [x] Supporting Information scope statement updated.
- [x] Cover-letter draft supplied.

## Scientific positioning

- [x] Main contribution framed as a chemical-informatics/molecular-modeling method.
- [x] Matched sequence-weighted HMMER3 benchmark added across six families.
- [x] Same alignments, labels, multiplicity ratios, replicate counts, and sample counts used in
  the SA/HMM comparison.
- [x] Full representative multiplicity sweep reported in Supporting Information.
- [x] Matched local ESM2 comparison reported for Kunitz at rho = 500.
- [x] Claims explicitly distinguish marker retention, model-based plausibility, and functional
  activity.
- [x] Low-confidence Cav2.2 complex-prediction analysis moved to Supporting Information and
  labeled a negative diagnostic.
- [ ] Add experimental activity measurements if they become available; otherwise preserve the
  present nonfunctional-claim framing.

## Items to confirm in the submission portal

- [x] Replace the bracketed preprint/exclusivity note in `cover-letter.md` with the correct
  statement and disclose any posted preprint URL/DOI.
- [ ] Confirm that the GitHub repository contains the exact submitted revision and is publicly
  accessible.
- [ ] Create a permanent archive (for example, Zenodo) and add its DOI to the Data and Software
  Availability section if available before submission.
- [ ] Upload `Paper_JCIM.pdf`, `Paper_JCIM_SI.pdf`, and the TOC graphic as separate files where
  the portal requests them.
- [ ] Enter funding information or explicitly select “no external funding,” as applicable.
- [ ] Supply suggested reviewers and any opposed reviewers, using institutional email addresses
  and a brief conflict-of-interest check.
- [ ] Verify author name, affiliation, ORCID, email, and corresponding-author designation in the
  portal.
- [ ] Run the final ACS compliance/author checklist presented by the portal.
